#Guia Per Contribuir al Proyecto

gracias por querer contribuir con este proyecto ^^

##Estilo del codigo

el codigo a ser posible que tenga tres partes:

1. inicialización de variables
2. proceso para obtener un resultado
3. resultado.

Una parte importante del estilo es que a de haber una linea en blanco despues de cada linea de codigo para darle legibilidad.

##Pull Request

para empezar debes hacer una rama aparte y luego ya podras trabajar

##Reporting Issues

para reportar cualquier error ser lo mas claros y especificos posibles, esto incluye cosas como el sistema operativo.
